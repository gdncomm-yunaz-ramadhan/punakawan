## Improvement summary

- Unified the shell, navigation, cards, status chips, icons, and theme selector with the Setara visual language.
- Restyled diff and review surfaces with GitHub-like file headers, line gutters, additions, and deletions.
- Reworked charts with a cohesive accessible palette, clearer grids, rounded bars, and stronger tooltips.
- Restyled dialogs, drawers, and bottom sheets with Setara-like hierarchy and focus treatment.
- Reworked workflow and relationship visuals into readable node-and-edge canvases. The workflow capture uses a temporary demonstration definition so the n8n-style canvas is visible; the definition was removed after capture.
- Reworked plan review into an Atlassian-inspired document and review layout with numbered sections, a focal review instruction, and clearer comment/action areas.
